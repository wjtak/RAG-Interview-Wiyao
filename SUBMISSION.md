# Submission Checklist

When you're done (or when the 2–3 hour limit is up), send us the following.
Email everything to **mohamed@weareaipartners.com** with subject
`RAG Interview — <Your Name>`.

## 1. Your code

- [ ] A link to a **Git repository** (GitHub/GitLab/Bitbucket), or a zip archive.
- [ ] A `README` explaining **how to run it locally** in a few commands.
- [ ] A `.env.example` showing which environment variables/keys are needed
      (do **not** commit real API keys or secrets).

## 2. A way to see it working

Provide **one** of:

- [ ] A **live URL** to the deployed chatbot (GCP preferred — see main README), **or**
- [ ] A short **screen recording / GIF** of it answering questions locally,
      plus clear run instructions.

## 3. Your notes

- [ ] A `NOTES.md` (a template is provided) covering:
  - Your overall approach and architecture.
  - Key choices and trade-offs (model, vector store, chunking, framework, cloud).
  - What you cut for time and what you'd do next.
  - Roughly **how long** you spent, and on what.

## 4. A quick self-check before sending

- [ ] Ask it something **in** the knowledge base — does it answer correctly?
- [ ] Ask it something **not** in the knowledge base — does it decline gracefully?
- [ ] Does the run/deploy path actually work from a clean checkout?

That's it. Thanks again — we're looking forward to it.
